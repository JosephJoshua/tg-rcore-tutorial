# Ch1-Ch2 SMP Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Create three new crates — SBI-SMP, ch1-smp, ch2-smp — that boot 4 RISC-V harts from M-mode, demonstrate SMP synchronization (ch1), and show multi-hart batch OS boot (ch2).

**Architecture:** Multi-hart M-mode boot in SBI (per-hart stacks, per-hart CLINT), S-mode per-hart stacks via `tp` register, spinlock/barrier primitives, 3 demos in ch1, secondary-hart WFI in ch2.

**Tech Stack:** Rust (no_std), RISC-V inline assembly, QEMU virt -smp 4 -bios none

- [ ] **Step 3: Rewrite m_entry.asm for multi-hart boot**

Replace the single-hart boot with:
1. `csrr t0, mhartid` — identify this hart
2. Guard: `bge t0, NUM_HARTS, .park_hart` — park excess harts
3. Per-hart stack: `sp = m_stacks_base + (hartid + 1) * 4096`
4. `csrw mscratch, sp` — per-hart M-mode trap stack
5. All existing CSR config (mstatus, mepc, mtvec, mideleg, medeleg, PMP, mcounteren)
6. `csrr a0, mhartid` + `mret` — pass hartid to S-mode
7. `.park_hart:` WFI loop
8. `.bss.m_stack` section: `M_STACK_SIZE * NUM_HARTS` (4 KiB × 4 = 16 KiB)

Key: `.equ NUM_HARTS, 4` and `.equ M_STACK_SIZE, 4096`

- [ ] **Step 4: Modify msbi.rs for per-hart CLINT timer**

In `handle_timer()`:
```rust
let hartid: usize;
unsafe { core::arch::asm!("csrr {}, mhartid", out(reg) hartid) };
let mtimecmp_addr = 0x200_4000 + 8 * hartid;
unsafe { (mtimecmp_addr as *mut u64).write_volatile(time) };
```

## Task 3: Implement ch1-smp SMP module and main

**Files:**
- Create: `jsph-tg-rcore-tutorial-ch1-smp/src/smp.rs`
- Rewrite: `jsph-tg-rcore-tutorial-ch1-smp/src/main.rs`

- [ ] **Step 1: Create smp.rs**

Implement from scratch (no external crate):
1. `pub const NUM_HARTS: usize = 4;`
2. `static BOOT_HART_DONE: AtomicBool` — Release/Acquire boot flag
3. `pub struct SpinLock` — TTAS (test-and-test-and-set) with `compare_exchange_weak`
4. `pub struct Barrier` — generation-based with `AtomicUsize` count + generation
5. `pub fn hart_id() -> usize` — reads `tp` register
6. `static PRINT_LOCK: SpinLock` — global lock for UART output
7. `pub fn locked_println!` or `locked_print` helper that acquires PRINT_LOCK

- [ ] **Step 2: Rewrite main.rs _start for multi-hart**

```rust
#[naked] unsafe extern "C" fn _start() -> ! {
    // a0 = hartid from M-mode
    // Save to tp immediately
    // Per-hart stack: HART_STACKS + (hartid + 1) * STACK_SIZE
    // Branch: hart 0 → rust_main, others → secondary_main
}
```

Constants: `STACK_SIZE = 64 * 1024`, `NUM_HARTS = 4`, stacks in `.bss.uninit`.

- [ ] **Step 3: Implement rust_main (hart 0)**

1. `zero_bss()` or manual BSS clear
2. Print "Hello, world!" (SBI console)
3. `BOOT_HART_DONE.store(true, Release)` — signal secondaries
4. Call `demo_sequence(0, NUM_HARTS)` (or inline demos)
5. Init VirtIO-GPU, render tangram (existing code, hart 0 only)
6. `shutdown(false)`

- [ ] **Step 4: Implement secondary_main**

1. Spin on `BOOT_HART_DONE.load(Acquire)`
2. Print identification with PRINT_LOCK
3. Call `demo_sequence(hart_id(), NUM_HARTS)`
4. After demos: idle loop (WFI or just return)

- [ ] **Step 5: Implement demo sequence**

**Demo 1 (unsynchronized):** All harts print multi-line message without lock. Barrier before/after.

**Demo 2 (synchronized):** Same messages with PRINT_LOCK. Barrier before/after.

**Demo 3 (parallel computation):** Hart 0 drives:
- Sequential: hart 0 does 4 workloads, measures time via `rdtime`
- Parallel: all 4 harts work simultaneously (use `AtomicUsize` result + barrier)
- Report speedup
- Use `core::hint::black_box()` or `read_volatile` to prevent optimization

- [ ] **Step 6: Verify cargo check passes on host**

Non-riscv64 stubs: keep existing stub module for `main()`, `__libc_start_main`, `rust_eh_personality`.
